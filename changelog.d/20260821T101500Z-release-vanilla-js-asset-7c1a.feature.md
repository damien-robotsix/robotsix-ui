Auto-release now uploads `dist/vanilla.js` (and its sourcemap) alongside `dist/style.css` on every version tag. The stylesheet has been fetchable without npm since v0.1.31, but the framework-free bundle it styles was not — so a server-rendered component could adopt the shared look and still had no way to mount `mountConfigPanel`. A new `robotsix_ui.vanilla_js_url()` helper resolves the URL, mirroring `css_url()`.
